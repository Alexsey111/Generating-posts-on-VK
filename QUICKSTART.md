# Быстрый запуск VK Post Generator

## 🚀 Быстрый старт

### Вариант 1: Обычная установка

#### 1. Установка зависимостей
```bash
# Установить все необходимые пакеты
make install-web
```

#### 2. Настройка переменных окружения
```bash
# Скопировать пример файла конфигурации
cp .env.example .env

# Отредактировать .env файл и указать ваши API ключи:
# - OPENAI_API_KEY - ключ от OpenAI
# - VK_API_KEY - токен ВКонтакте
# - VK_GROUP_ID - ID группы ВК
# - SECRET_KEY - секретный ключ для Flask
```

#### 3. Инициализация базы данных
```bash
# Создать базу данных и таблицы
make init-db
```

#### 4. Запуск приложения
```bash
# Запустить веб-сервер
make run-web
```

### Вариант 2: Запуск в Docker 🐳

#### 1. Подготовка
```bash
# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env файл с вашими API ключами
```

#### 2. Запуск через Docker Compose
```bash
# Запуск всех сервисов (приложение + PostgreSQL)
docker-compose up -d

# Инициализация базы данных
docker-compose exec app python init_db.py
```

#### 3. Открыть в браузере
Перейдите на: http://localhost:5000

### 5. Открыть в браузере
Перейдите на: http://localhost:5000

## 📋 Что дальше?

1. **Зарегистрируйтесь** - создайте аккаунт в приложении
2. **Создайте пост** - перейдите в раздел "Создать пост"
3. **Опубликуйте** - нажмите кнопку публикации в ВКонтакте
4. **Отслеживайте** - смотрите статистику в панели управления

## 🔧 Альтернативные команды

Если у вас не работает Makefile, используйте прямые команды:

```bash
# Установка зависимостей
pip install flask flask-login flask-wtf flask-sqlalchemy werkzeug openai python-dotenv requests

# Инициализация базы данных
python init_db.py

# Запуск приложения
python app.py
```

## 🐳 Docker команды

```bash
# Просмотр логов
docker-compose logs -f app

# Остановка контейнеров
docker-compose down

# Пересборка и запуск
docker-compose up -d --build

# Подключение к контейнеру
docker-compose exec app bash
```

## ⚠️ Важные заметки

- Убедитесь, что API ключи в файле `.env` корректны
- В продакшене обязательно используйте HTTPS
- Регулярно обновляйте зависимости для безопасности
- Настройте резервное копирование базы данных
- Для Docker: PostgreSQL будет доступен на порту 5432

## 🆘 Проблемы?

Если возникают ошибки:

1. **Обычная установка**:
   - Проверьте, что все зависимости установлены
   - Убедитесь, что файл `.env` настроен правильно
   - Проверьте логи в консоли
   - Убедитесь, что порт 5000 не занят другим приложением

2. **Docker установка**:
   - Убедитесь, что Docker и Docker Compose установлены
   - Проверьте, что порты 5000 и 5432 свободны
   - Просмотрите логи: `docker-compose logs app`
   - Пересоберите контейнеры: `docker-compose up -d --build`
